Cada uno de los **20 proyectos** está **terminado y listo para ejecutar**. No necesitas saber programar de antemano, ni instalar librerías externas.

## Empieza aquí

## Contenido de cada carpeta

- `solucion.py`: programa completo, listo para ejecutar.
- `enunciado.md`: descripción del problema y requisitos.
- `explicacion.md`: cómo se ha diseñado la solución.
- `GUIA_PASO_A_PASO.md`: explicación de funciones y conceptos para principiantes.
- `README.md`: presentación e instrucciones.

### Ejecutar

```powershell
cd 01_calculadora
py solucion.py
```

### Verificar todos los programas

Desde la raíz del ZIP: `py comprobar_proyectos.py`.

### Subir a GitHub

Puedes publicar **un solo proyecto** como repositorio independiente siguiendo `EMPIEZA_AQUI.md`. Explica de dónde obtuviste el código y qué cambios personales hiciste.
