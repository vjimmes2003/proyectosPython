# Enunciado — Registro de asistencia

**Proyecto 17 · Nivel básico-intermedio · Python 3.10+**

## Situación y objetivo

Controlar la asistencia diaria de un grupo.

## Requisitos obligatorios

1. Dar de alta estudiantes.
2. Marcar presente, ausente o retraso por fecha.
3. Consultar registro de una fecha y porcentaje de presencia.
4. Guardar datos en JSON.

## Requisitos de programación

- Crear un programa de consola interactivo, con salida clara y opción de finalizar.
- Dividir la solución en funciones con nombres significativos.
- Validar las entradas del usuario y evitar caídas por datos incorrectos.
- Usar listas o diccionarios cuando el problema lo requiera.
- Escribir código legible, con comentarios que expliquen decisiones importantes.

## Ampliación voluntaria

Contabilizar retrasos con una penalización configurable.

## Entregables

1. `solucion.py` funcionando sin librerías de terceros.
2. `explicacion.md` que describa estructura, algoritmos y decisiones.
3. Capturas o pruebas manuales de las opciones principales.

## Criterios orientativos de evaluación

| Criterio | Peso |
|---|---:|
| Requisitos funcionales | 40 % |
| Validaciones y casos límite | 25 % |
| Organización en funciones | 20 % |
| Claridad y documentación | 15 % |

## Ejecución

Desde esta carpeta:

```bash
python solucion.py
```

El programa puede crear archivos de datos en esta carpeta durante su uso.
